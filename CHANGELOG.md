# Changelog

## 0.1.0

**EN**
- First build: glass surface in groovex design, LIVE screen in demo mode (5 track cards, REC/PLAY/DUB on touch-down, multi-touch, levels, waveforms).
- In-app updater: checks GitHub Releases (Stable/Beta), downloads, verifies SHA-256, installs.
- Samsung DeX / external displays: freely resizable window, large layout for big windows.

**DE**
- Erster Build: Glas-Oberfläche im groovex-Design, LIVE-Ansicht im Demo-Modus (5 Track-Karten, REC/PLAY/DUB beim Berühren, Multitouch, Pegel, Wellenformen).
- In-App-Updater: prüft GitHub Releases (Stabil/Beta), lädt herunter, prüft SHA-256, installiert.
- Samsung DeX / externe Bildschirme: frei skalierbares Fenster, großes Layout für große Fenster.
